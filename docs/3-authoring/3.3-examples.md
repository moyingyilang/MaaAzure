# 3.3 · 两个完整示例

**位置**：`3-authoring` › 3.3 ｜ 前置：[3.2 节点树](3.2-node-tree.md)

选这两个，是因为它们正好是边界的两端：**委托几乎全是 JSON，战役几乎全是 Rust。**

---

## 示例一 · 委托（纯 Pipeline）

场景：进委托 → OCR 四条剩余时间 → 选最该领的 → 领取 → 回主界面。

```
resource/pipeline/1-daily/commission/
├── entry.json     CommissionStart + done
└── nodes.json     业务节点
```

`entry.json`：

```jsonc
{
  "CommissionStart": {
    "recognition": "DirectHit",
    "next": ["commission_enter", "[Anchor]home"]
  },
  "commission_done": {
    "recognition": "DirectHit",
    "next": []
  }
}
```

`nodes.json`：

```jsonc
{
  "commission_enter": {
    "recognition": "TemplateMatch",
    "template": "cn/commission/entry_button.png",
    "roi": [1100, 600, 1280, 720],
    "action": "Click",
    "next": ["commission_page", "commission_recover"]
  },

  "commission_page": {
    "recognition": "TemplateMatch",
    "template": "cn/commission/page_title.png",
    "action": "Screencap",
    "next": ["commission_pick", "commission_empty", "commission_confirm"]
  },

  "commission_pick": {
    "recognition": "Custom",
    "custom_recognition": "CommissionPick",
    "action": "DoNothing",
    "next": ["commission_confirm", "commission_recover"]
  },

  "commission_empty": {
    "recognition": "OCR",
    "roi": [360, 200, 920, 400],
    "expected": ["没有可领取", "No commission"],
    "action": "DoNothing",
    "next": ["[Anchor]home"]
  },

  "commission_confirm": {
    "recognition": "TemplateMatch",
    "template": "cn/commission/confirm.png",
    "action": "Click",
    "next": ["commission_page", "[Anchor]home"]
  },

  "commission_recover": {
    "recognition": "DirectHit",
    "next": ["[Anchor]home"]
  }
}
```

配套 Rust（`crates/domain/daily/src/lib.rs`，已实现）：

```rust
pub fn pick_commission(slots: &[CommissionSlot]) -> Option<&CommissionSlot> {
    slots.iter().min_by_key(|s| (!s.urgent, s.remaining_secs))
}
```

要点：

- 8 个节点里只有 1 个 Custom，因为它要做「解析 4 行 + 比较 + 算坐标」。
- `commission_page.next` 同时挂了 pick/empty/confirm，一帧内并行判断。
- 没有一行 Rust 负责「点哪个按钮」——那是 Pipeline 的事。

## 示例二 · 战役（JSON 外壳 + Rust 内核）

战役的难点（`map_detection/` 2,783 行 + `map/` 5,522 行）**无法 Pipeline 化**，
但外壳可以：

```jsonc
{
  "CampaignStart": {
    "recognition": "DirectHit",
    "next": ["campaign_battle_prepare", "campaign_select_chapter", "[Anchor]home"]
  },

  "campaign_select_chapter": {
    "recognition": "Custom",
    "custom_recognition": "CampaignChapterSelect",
    "action": "DoNothing",
    "next": ["campaign_battle_prepare", "campaign_recover"]
  },

  "campaign_battle_prepare": {
    "recognition": "TemplateMatch",
    "template": "cn/campaign/battle_prepare.png",
    "action": "Custom",
    "custom_action": "CampaignPrepare",
    "next": ["campaign_in_map", "campaign_recover"]
  },

  "campaign_in_map": {
    "recognition": "Custom",
    "custom_recognition": "CampaignMapStep",
    "action": "DoNothing",
    "max_hit": 200,
    "next": ["campaign_combat", "campaign_map_end", "campaign_in_map"]
  },

  "campaign_combat": {
    "recognition": "TemplateMatch",
    "template": "cn/campaign/in_combat.png",
    "action": "Custom",
    "custom_action": "CampaignCombat",
    "next": ["campaign_in_map", "campaign_result"]
  },

  "campaign_map_end": {
    "recognition": "Custom",
    "custom_recognition": "CampaignFinished",
    "action": "DoNothing",
    "next": ["campaign_result", "campaign_in_map"]
  },

  "campaign_result": {
    "recognition": "TemplateMatch",
    "template": "cn/campaign/result_screen.png",
    "action": "Click",
    "next": ["campaign_done"]
  },

  "campaign_done": { "recognition": "DirectHit", "next": [] },
  "campaign_recover": { "recognition": "DirectHit", "next": ["[Anchor]home"] }
}
```

Rust 侧形状（`domain/battle`）：

```rust
pub enum CampaignState { EnterMap, DetectMap{grid: Grid}, PlanRoute{path: Vec<Node>},
                         MoveFleet{step: usize}, InCombat, Settle, Done }

pub fn step(&mut self, frame: Frame<'_>, view: &MapView) -> Result<Option<Command>>;
```

**设计意图**：Pipeline 只回答「现在该干哪类事」，每类事内部是一个完整状态机。
于是：

- Rust 状态机可以脱离 MaaFW 单测（喂录像，见 [5.2](../5-engineering/5.2-testing.md)）
- 战场 UI 改版只动 JSON，不动 Rust
- Rust 决策改逻辑只动 Rust，不动 JSON

## 接线前先读旧仓

写 `Daily` 的接线时我先猜了一版「主界面→任务→每日」，跑不通也不好判断对错。
后来直接翻旧仓的 `module/daily/daily.py`，开头就写着：

```python
from module.ui.page import page_campaign_menu, page_daily
```

也就是说路径是**出击 → 每日**，不是我猜的「任务 → 每日」。换成
`ui_main_goto_campaign` → `ui_campaign_goto_daily` 后一次通过。

**结论：接线前先花两分钟看旧仓对应模块的 import 和 `ui_click(...)` 调用**，
比对着节点名猜快得多，也不会把猜测写进拓扑。
