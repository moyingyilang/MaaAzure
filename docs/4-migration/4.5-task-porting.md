# 4.5 · 任务移植：从上游 Python 到 Pipeline

**位置**：`4-migration` › 4.5 ｜ 前置：[4.3 战役数据](4.3-campaign-data.md)

> 现状：我们只移植了「登录 + 委托入口」。这一页定下**逐任务移植的标准做法**，
> 避免每个任务各写一套。

## 1. 三步映射法

上游每个任务都是一个 `run()` 方法，里面有若干 `while 1:` 状态循环。移植时按三张表走：

| 上游写法 | 落到哪里 | 说明 |
|---|---|---|
| `self.ui_ensure(page_x)` | `nav_*` 节点 | 页面导航已有 `pages.json`，复用 |
| `if self.appear(BTN): click(BTN)` | 节点 `recognition` + `action: Click` | 一格一个节点 |
| `while 1:` + 退出条件 | 节点的 `next` 图 + `timeout` | 退出条件 = `next` 里排最后的终止节点 |
| `OCR` / `Digit` 判断 | `recognition: OCR` + `expected` | 需要 OCR 的放最后，能模板匹配就别 OCR |
| 业务算法（选哪个委托） | Rust 自定义识别/动作 | 用 `custom_recognition` 走 `maazure-agent` |
| `self.device.sleep((0.5,1))` | `post_delay` / `pre_delay` | 随机区间取中值 |

**硬规则：`timeout` 写在「要被解析的 next 的那一层」**（MaaFW 文档原文），
不是写在等待目标节点上。

## 2. 委托任务（Commission）的映射表

上游 `module/commission/commission.py` 的子流程与节点对应关系：

| 上游函数 | 作用 | 我们的节点（计划） |
|---|---|---|
| `run()` 开头 | 处理战术课堂弹窗 | `commission_tactical_cancel`（`use`: TACTICAL_CLASS_START / CANCEL） |
| `ui_ensure(page_reward)` | 进任务页 | `commission_goto_reward` + `_white` 孪生 |
| `commission_receive()` | 领取已完成委托 | `commission_receive_*`（点击领取 → 确认） |
| `handle_info_bar()` | 关掉「获得舰船」信息栏 | `commission_info_bar_close` |
| `_commission_ensure_mode()` | 切换 日常/紧急 模式 | `commission_mode_daily` / `commission_mode_urgent`（`Switch` 语义用两个节点） |
| `_commission_scan_all()` | 扫描委托列表 | 需要 OCR（剩余时间）+ 滚动，`Scroll` 动作 |
| `_commission_choose()` | 选最优委托（算法） | Rust `custom_recognition: CommissionPick` |
| `_commission_start_click()` | 点开始 → 选委托 → 确认 | `commission_start_click` → `commission_pick` → `commission_confirm` |
| `self.daily.add_by_eq(self.urgent)` | 统计完成时间、安排下次 | 交给调度器（Rust 侧），Pipeline 只负责「跑到没有可接委托」 |

## 3. 每个任务的验收标准（强制）

移植一个任务必须同时满足：

1. `xtask check` 0 错误、0 接线歧义；
2. 至少一个合成帧 fixture，断言 `visited` 路径与 `outcome`；
3. 真机跑一次：从 `start_game` 到任务结束，节点统计里能看到该任务的关键节点被执行；
4. 文档 `6.2-task-tree.md` 里把该任务标记为 ✅ 并写明「真机验证日期」。

## 4. 移植顺序（按依赖从少到多）

| 顺序 | 任务 | 上游模块 | 依赖 |
|---|---|---|---|
| 1 | Commission | `module/commission/` | 无（P0 验收任务） |
| 2 | Reward | `module/reward/` | 只需点击 |
| 3 | Daily | `module/daily/` | 需要地图（出击） |
| 4 | Tactical | `module/tactical/` | 点击 + OCR 技能经验 |
| 5 | Dorm | `module/dorm/` | 点击 + OCR 食物 |
| 6 | Meowfficer | `module/meowfficer/` | 点击 + OCR |
| 7 | Guild | `module/guild/` | 点击 + 派遣 |
| 8 | Research | `module/research/` | 大量 OCR + 队列 |
| 9 | Exercise | `module/exercise/` | 战斗（需要 map） |
| 10 | Gacha | `module/gacha/` | 只读（不消耗资源） |
