# 1.1 · 架构决策

**位置**：`1-foundation` › 1.1 ｜ 前置：无 ｜ 后继：[1.2 边界](1.2-boundaries.md)

每条决策都必须写出**代价**。没有代价的决策是幻觉。

```
起点：AzurPilot
├── 288,076 行 Python / 2,037 文件        ← 维护面积的来源
├── 93 个任务 / 2,185 个视觉资源          ← 领域知识
├── 0 个游戏逻辑自动化测试                ← 最大风险
└── 单帧 350ms 中 99% 是等截图            ← 性能真相
      │
      ▼ 12 条决策
目标：MaaAzure = MaaFramework 内核 + Pipeline 外壳 + Rust 领域
```

| ID | 决策 | 代价 | 收益 |
|---|---|---|---|
| **DEC-001** | 用 MaaFramework 做执行内核 | 受上游 API 演进约束；LGPL 合规需动态链接 | 删掉 12,831 行设备层 + 2,258 行 OCR |
| **DEC-002** | 复杂逻辑用 Rust | 编译慢；CV 代码自己写 | FFI 成本最低；无 GC，帧预算可预测；单二进制 |
| **DEC-003** | 流程用 Pipeline JSON | 无编译期检查，靠 `pipeline-check` | 删掉 2,220 行 A* 寻路；无「忘记 continue」类 bug |
| **DEC-004** | 独立仓库，旧仓冻结 | 数据单向同步 | 双轨灰度、随时回退 |
| **DEC-005** | 自托管 daemon，不把调度交给 PI Client | 要自己写 Web | PI 的 `task` 列表表达不了 NextRun/优先级/失败接管 |
| **DEC-006** | `interface.json` 是唯一配置 schema | 迁移器必须完备 | 2,401 项 → 强类型；多语言与 GUI 免费 |
| **DEC-007** | 分辨率走 720 短边归一化 | 依赖 MaaFW 缩放质量 | 7,786 张图**原样复用** |
| **DEC-008** | 战役 `.py` → JSON 数据 | 需要一次性转换器 | 1,436 个文件不再参与编译 |
| **DEC-009** | 先建 golden corpus | 3–4 天前置投入 | 之后每次改动都能验证 |
| **DEC-010** | 许可证 **AGPL-3.0** | 比 GPL 更严：网络服务也须开源 | 与 MaaEnd 生态同协议；防止闭源 SaaS 分叉 |
| **DEC-011** | **树状组织**：目录与 crate 按层分树 | 路径变长 | 每个文件有唯一归属；新增模块不改别人的目录 |
| **DEC-012** | 每个 crate 只依赖**同层或更低层** | 偶尔要多写一层 | 无环依赖；地基可在无 SDK 机器上测试 |

## DEC-010 · 为什么是 AGPL 而不是 GPL

| 项目 | 协议 | 与我们的关系 |
|---|---|---|
| AzurPilot（数据与领域知识来源） | GPL-3.0 | 衍生作品必须 GPL 系；GPLv3 §13 允许并入 AGPLv3 作品 |
| MaaFramework | LGPL-3.0 | 动态链接 + 不修改 + 可替换 → 合规 |
| MaaEnd（架构参照） | AGPL-3.0 | 同协议后**法律上可组合**，但不同游戏，仍不复制代码 |
| **MaaAzure** | **AGPL-3.0** | 我们自己的选择 |

两条红线不变：

1. 不复制 MaaEnd 的代码——理由从「协议不许」变成「没必要」：游戏不同、语言不同、引入即增加维护面积。
2. `tools/buildkit/` 派生自 MPL-2.0 的 JMNeXt，该目录下改过的文件保持文件头声明。

## DEC-011 · 树状 vs 平坦

旧仓是平坦的：`module/` 下 60 个平级目录，`module/base/` 里塞了 20 个互不相关的工具。
新增功能时没人知道该放哪，于是出现 2,037 个文件里散落的同义实现。

新仓强制树：

```
crates/
├── foundation/   只放「任何游戏都能用」的东西
├── domain/       只放「碧蓝航线知识」
├── runtime/      只放「和 MaaFramework 打交道」的东西
└── apps/         只放「入口」
```

判据：**如果一段代码不知道碧蓝航线是什么也能写出来，它就不属于 `domain/`。**
反过来说，`domain/` 里出现 `controller.post_click()` 就是越界。
