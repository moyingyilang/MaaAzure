# 1.3 · 术语对照

**位置**：`1-foundation` › 1.3 ｜ 前置：[1.1](1.1-decisions.md)

新线大量复用旧仓词汇（领域知识不变），但**归属和执行者变了**。这张表是唯一的对照依据。

## 核心概念树

```
MaaAzure
├── 资源包（resource bundle）
│   ├── pipeline/     流程声明（JSON）
│   ├── image/        模板图（PNG）
│   └── model/        神经网络模型（暂无）
├── 节点（node）
│   ├── 识别（recognition）  TemplateMatch / OCR / ColorMatch / FeatureMatch / NN / Custom
│   └── 动作（action）       Click / Swipe / Scroll / Key / Screencap / Custom
├── 锚点（anchor）      命名回跳点，[Anchor] 与 [JumpBack] 引用
├── 任务（task）        一个 Start 入口 + 若干节点
├── 实例（instance）    一个模拟器 + 一个 Controller + 一个 Tasker
└── 决策（decision）    领域 crate 的输出：命令 or 选择结果
```

## 旧名 → 新名

| 旧 | 新 | 说明 |
|---|---|---|
| `Button(area, color, button, file)` | 节点 `{recognition, template, roi, target}` | `area`→`roi`，`button`→`target`，`color`→`ColorMatch.expected` |
| `Template(file)` | 节点 `{recognition: TemplateMatch}`（无 roi） | 全屏模板；动图 → 目录模板 |
| GIF 动图模板 | `image/<s>/<m>/<node>/frame_NN.png` 目录 | MaaFW 不支持 GIF，抽帧成目录 |
| `appear(BTN)` | 节点被 `next` 命中 | 不再有独立函数 |
| `appear_then_click(BTN, interval=2)` | 节点 + `action: Click` + `rate_limit: 2000` | interval 就是 rate_limit |
| `ui_goto(page)` / `ui_ensure` | `next` 图遍历 | 无显式寻路 |
| `Page(check_button, links)` | 节点 `next` 列表 | 图即页面 |
| `Navbar` / `Switch` / `Scroll` | 节点 + `Next`/`Swipe`/`Scroll` 动作 | 无专用类 |
| `Digit` / `DigitCounter` / `Duration` | `OCR` 节点 + `maazure-vision` 后处理 | 引擎给文本，我们纠错 |
| `Ocr(image, area)` | `OCR` 节点 + `roi` | —— |
| `self.config.Group_Argument` | `interface.json` 的 `option` → 生成强类型 | 编译期检查 |
| `RequestHumanTakeover` | `AzureError::HumanTakeover` | 错误树 `Fatal` 分支 |
| `'recoverable'` | `TaskOutcome::Recoverable` | —— |
| `GameStuckError` | `AzureError::GameStuck` | —— |
| `device.screenshot()` | `Engine::screenshot()` | 只在 runner 里 |
| `device.click(x, y)` | `Engine::click(Point)` | —— |
| `alas.json` 配置 | `config/instance.json` | PI v2 生成 |
| `module/*/assets.py` | `resource/pipeline/gen/*.json` | 自动生成，不手改；2,753 个叶子 |
| `campaign/<map>.py` | `data/campaign/<map>.json` | 数据即数据 |

## 命名规范

| 对象 | 规范 | 例 |
|---|---|---|
| 节点 | `<domain>_<state>` 小写下划线 | `commission_page` |
| 任务入口 | `<Domain>Start` 大驼峰 | `CommissionStart` |
| 图片 | `image/<server>/<domain>/<state>.png` | `image/cn/commission/page.png` |
| Rust 类型 | 大驼峰；错误 `*Error`；状态机 `*Machine` | `CampaignMachine` |
| 文档 | `<层号>.<序号>-<主题>.md` | `4.2-assets.md` |
