# 1.2 · 边界：什么写成什么

**位置**：`1-foundation` › 1.2 ｜ 前置：[1.1](1.1-decisions.md) ｜ 后继：[3.1 Pipeline 规范](../3-authoring/3.1-pipeline-spec.md)

整个重写最容易翻车的地方不是技术，是**把该声明的东西写成代码，把该写代码的东西塞进 JSON**。
本文给出判定树，三条判据走完必有唯一归属。

## 判定树

```
一段逻辑
│
├─ 只依赖当前这一帧截图？
│   └─ 是 ─▶ 它需要跨帧记忆吗（第几页/第几次/上次走到哪）？
│              ├─ 否 ─▶ 【Pipeline JSON】看 A 点 A
│              └─ 是 ─▶ 【Rust 领域】状态机
│
└─ 否（需要多帧信息 / 计算 / 外部数据）
    │
    ├─ 是纯计算，不需要屏幕？（排序、评分、寻路、解析时长）
    │   └─ 是 ─▶ 【Rust 领域】纯函数，可单测
    │
    └─ 需要连续多步 UI 操作才能完成一件事？（战役一局、大世界一条线路）
        └─ 是 ─▶ 【Rust 状态机 + Pipeline 外壳】
```

## 三分表

| 归属 | 判据 | 典型 | 反例（会打回） |
|---|---|---|---|
| **Pipeline JSON** | 帧内闭合、无跨帧记忆、动作是原子 UI 操作 | 「主界面 → 委托 → 领取 → 返回」 | 在节点里用 `max_hit` 当循环计数做业务分支 |
| **Rust 领域（纯逻辑）** | 需要比较/排序/建模/计算，不产生副作用 | 委托选最短、科研评分、A* 寻路、网格预测 | 函数里调 `post_click()` |
| **Rust 领域（状态机）** | 跨帧记忆，且每帧只产出一个命令 | 战役一局、大世界一条线、战斗决策 | 在状态机里 `sleep` 或自己截图 |
| **Rust 运行时** | 和 MaaFramework / 设备 / 进程打交道 | Controller、Tasker、事件桥、调度器 | 领域 crate 里 `use maa_framework` |

## 三条硬判据

1. **帧内闭合**：识别与决策只依赖当前这张图。
   反例：委托选最短要 OCR 四行文本再比较——四行在同一帧内，但**比较**需要结构化数据。
   所以：识别部分可以是 Pipeline（OCR 节点），**决策部分**是 Rust。
2. **跨帧记忆**：需要「第几页、第几次、上次走到哪」。
   反例：翻页找关卡——如果写成 `max_hit` 循环，日志里看不出「在第 3 页」，出错无法复盘。
3. **原子动作**：一个动作只是点击/滑动/按键。
   反例：「进战役并打完一局」不是原子动作，它是状态机。

## 已知的强制 Rust 清单

这些**不可能**用 Pipeline 表达，提前认账，避免 P1 阶段发现「抽象错了」：

| 功能 | 需要的能力 | 旧模块 |
|---|---|---|
| 委托/科研列表选择 | 解析 + 排序 | `module/commission/` `module/research/` |
| 战役寻路 | 网格建模 + A* | `module/map/` |
| 地图检测 | 单应性 + 透视 + 网格预测 | `module/map_detection/` |
| 战斗撤退 | 血量比率 + 阈值 | `module/combat/` |
| 商店购买决策 | 价格/需求比较 | `module/shop/` |
| 大世界路线 | 图状态机 + 资源约束 | `module/os*`（6 个目录） |
| 岛屿经营 | 结算模拟 | `module/island/` |

## 反面案例（来自旧仓）

| 旧写法 | 问题 | 新归属 |
|---|---|---|
| `while 1: if self.appear_then_click(A, interval=2): continue` × 5 层 | 无状态机，出错无法复盘 | Pipeline `next` 图 |
| `for _ in range(4): self.device.click(...)` | 硬编码次数，界面改版即失效 | Pipeline 4 个节点 或 `Scroll` + Rust |
| `module/ui/page.py` 里 A* 寻路 2,220 行 | 通用问题重复实现 | Pipeline `next` + `anchor` |
| `campaign/*.py` 1436 个数据文件 | 数据编译进代码 | `data/campaign/*.json` |

## 一句话判据（写代码前默念）

> **「这段逻辑如果游戏 UI 完全一样、但换个游戏，还需要吗？」**
> 需要 → 它可能属于 `foundation/`；不需要 → 它是碧蓝航线知识，属于 `domain/` 或 JSON。
