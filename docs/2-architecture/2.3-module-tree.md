## 逐项判据

| 旧模块 | 行数 | 处置 | 依据 |
|---|---|---|---|
| `device/` | 12,831 | **删除** | MaaFW Controller 已覆盖且更全（ADB/Win32/PlayCover/Linux） |
| `ocr/` | 2,258 | 删引擎、留后处理 | 引擎用内置；`I→1` 这类纠错保留在 `vision` |
| `ui/` | 2,220 | **删除** | `next` 图 + `anchor` 天然是寻路器 |
| `base/template.py` | ~300 | 删除 | TemplateMatch 节点 |
| `base/button.py` | ~400 | 删除 | 节点字段（`roi`/`target`） |
| `base/mask.py` | ~200 | 删除 | TemplateMatch 支持 alpha mask |
| `webui/` | 18,573 | 重写 | axum + 复用 `assets/spa` 静态资源 |
| `config/` | 5,966 | 重写 | PI v2 `interface.json` |
| `map_detection/` | 2,783 | 重写 | 纯 Rust：单应性 + 网格预测 |
| `map/` | 5,522 | 重写 | 纯 Rust：相机 + 舰队 + 寻路 |
| `combat/` | 2,651 | 重写 | 状态机 |
| `campaign/` | 4,905 | 重写 | 状态机 + JSON 数据 |
| `os*` | ~19,000 | 重写（P3） | 最大状态机，最后做 |
| `island/` | 14,098 | 重写（P3） | 结算逻辑，纯 Rust 反而更清晰 |
| `statistics/` | 5,922 | 重写（P4） | 独立服务 |
| `submodule/` | ~2,000 | **不迁移** | MAA 抄作业能力由 MaaFW 生态的 Copilot 直接提供 |
