**自带 SDK，版本固定。** 不要求用户自己装 MaaFramework（DEC-001 的代价之一就是我们来管版本）。

## 版本号

| 号 | 位置 | 谁改 |
|---|---|---|
| 项目版本 | `interface.json.version` | `xtask release` |
| 代码版本 | `Cargo.toml` workspace `version` | `xtask release` |
| PI 协议 | `interface_version: 2` | 只在 PI 主版本变化时改 |
| MaaFW SDK | `MAA-*/README` 记录 | 升级时人工确认 |

`xtask release` 把前两个改成同值，并断言 SDK 版本在支持范围（MaaFW 5.x + `maa-framework` 1.x）。

## 发布检查单

```
[ ] cargo test --workspace 全绿
[ ] cargo run -p xtask -- pipeline-check 全绿
[ ] replay 全量用例通过
[ ] 版本号三处一致
[ ] data/ 与 resource/ 无残留调试文件
[ ] 无 *.py 进入 crates/ resource/ data/（grep 门禁）
[ ] tools/buildkit 文件保留 SPDX 头
[ ] 压缩包内含 LICENSE（AGPL-3.0）与 NOTICE
[ ] sha256 校验文件
```

## 自动更新

沿用 MaaFW 生态约定（PI 协议明确建议）：**只提供对 GitHub Release 的更新**，
不单独更新 UI 本体或 MaaFW，避免版本混搭。

## 许可合规（每次发布都要过）

| 要求 | 做法 |
|---|---|
| AGPL-3.0 全文随包 | 压缩包内含 `LICENSE` |
| 归属声明 | 内含 `NOTICE`（AzurPilot / MaaFramework / MaaEnd / JMNeXt） |
| LGPL 可替换 | `MaaFramework.dll` 独立文件，未打包进 exe |
| 源码可得 | Release 附上对应 tag 的源码链接 |
