# 6.4 · 12 个用例的录制手册

**位置**：`6-plan` › 6.4 ｜ 前置：[5.2 测试](../5-engineering/5.2-testing.md)

本机（Termux）没有模拟器，`uv run` 也会卡在 psutil 编译。这份手册是给**有 Windows 机器 +
跑着游戏的模拟器**时照着敲的，每一步都写清验收标准。

## 一次性的环境准备

```powershell
# 1) 旧仓（录制对象，已冻结）
git clone https://github.com/wess09/AzurPilot
cd AzurPilot
git checkout 86a9463d4
uv sync --frozen

# 2) 新仓（录制器在这）
git clone https://github.com/moyingyilang/MaaAzure
```

`record_golden.py` 依赖 PIL，AzurPilot 的 `.venv` 里有。

## 录制单个用例

```powershell
cd AzurPilot
uv run python ..\MaaAzure\tools\corpus\record_golden.py `
    --task commission --config alas --out ..\MaaAzure\corpus
```

参数说明：

| 参数 | 含义 |
|---|---|
| `--task` | AzurPilot 的任务方法名（`alas.py` 上的方法，小写） |
| `--config` | 配置名，对应 `config/<name>.json` |
| `--out` | 语料输出目录（建议 `MaaAzure\corpus`，已在 `.gitignore`） |
| `--max-frames` | 保险丝，默认 4000 帧 |

录制前**先把游戏摆到用例的起点**（见下表），再执行命令。脚本不负责导航，它只录。

## 12 个用例

| # | 用例名 | `--task` | 起始画面 | 验收 |
|---|---|---|---|---|
| 1 | 启动登录 | `startup` | 游戏未启动 | `case.json` 有帧；末尾能看到主界面确认 |
| 2 | 委托领取 | `commission` | 主界面 | 出现 `commission_pick` 的 OCR 文本 |
| 3 | 宿舍补充 | `dorm` | 主界面 | 有滑动动作（`swipe`） |
| 4 | 科研收取 | `research` | 主界面 | 有 OCR 计数 |
| 5 | 战术学院 | `tactical` | 主界面 | 纯点击，无 OCR |
| 6 | 商店购买 | `shop_frequent` | 商店页 | 能看到滚动 |
| 7 | 每日奖励 | `reward` | 主界面 | 多弹窗收敛 |
| 8 | 主线推图 | `main` | 主界面，3-4 已解锁 | 有地图移动 |
| 9 | 活动战役 | `event` | 主界面，活动开放 | 关卡选择 |
| 10 | 大世界日常 | `opsi_daily` | 主界面 | 世界地图 |
| 11 | 战斗撤退 | `main`（血量低时） | 战斗中 | 出现撤退决策 |
| 12 | **断连恢复** | `restart` | 运行中拔 ADB | 录制不中断，能看到重连 |

12 号最容易被跳过，却覆盖最不可测的部分——**录制器必须能扛住异常**，
`run_task` 的 `except BaseException` 就是为了这个：连崩溃也要录下来。

## 录完的自检

```bash
cd MaaAzure
python3 tools/corpus/record_golden.py --selftest --out corpus   # 格式是否仍然自洽
cargo run -p maazure-daemon -- --replay corpus/commission       # 回放能否走通
```

`--replay` 的输出应当是「帧数 = case.json 里的 frames」，且每条决策都能对上帧号。

## 语料怎么入库

**不进 git**（`.gitignore` 里已有 `/corpus/`）。一个日常任务 30–50MB，20 个就是 1GB。
放 release 附件或本地缓存，CI 需要时按需下载（[5.2](../5-engineering/5.2-testing.md) §7）。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `请在 AzurPilot 仓库根目录运行` | cwd 不对 | `cd AzurPilot` 后再跑 |
| 录到 0 帧 | `screenshot` 没被调到（任务秒退） | 看 AzurPilot 日志，先让它能正常跑完 |
| 决策全空 | 旧版走的是 `while` 里的 `appear_then_click` 内联逻辑 | 正常，`hits` 会记到 `appear` 上 |
| 帧数爆炸 | 任务里有高频循环 | 调小 `--max-frames`，或先修任务逻辑 |
